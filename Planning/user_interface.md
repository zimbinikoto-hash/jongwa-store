# Jongwa Store - User Interface Design

## 1. Introduction

The Jongwa Store user interface is designed to provide a simple and user-friendly shopping experience for buyers and an easy-to-use management platform for vendors.

The application uses clear navigation, forms, buttons and messages to help users complete tasks efficiently.

## 2. Home Page

The home page provides access to the main features of Jongwa Store.

It includes:

- Jongwa Store name and logo.
- Navigation menu.
- Home link.
- Products link.
- Login link.
- Registration link.
- Available products from different vendors.
- Product information and prices.
- Access to the shopping cart.
- Search functionality, where implemented.

## 3. Registration Page

The registration page allows new users to create accounts.

### Registration Fields

- Username.
- Email address.
- Password.
- Confirm password.
- Account type (Vendor or Buyer).
- Register button.

Users are redirected to the login page after successful registration.

## 4. Login Page

The login page allows registered users to access their accounts.

### Login Fields

- Username.
- Password.
- Login button.
- Forgot Password link.
- Registration link for new users.

The system authenticates users and provides access according to their assigned roles.

## 5. Vendor Dashboard

The vendor dashboard allows vendors to manage their stores and products.

### Dashboard Features

- Welcome message.
- Create a new store.
- View registered stores.
- Edit store details.
- Delete stores.
- Add new products.
- View products.
- Edit product details.
- Delete products.
- Manage product prices.
- Update stock quantities.

Vendors can only manage their own stores and products.

## 6. Product Catalogue

The product catalogue allows buyers to browse products available on Jongwa Store.

### Product Information

- Product name.
- Product description.
- Product image, where available.
- Product price.
- Available stock.
- Store information.
- Add to Cart button.

Buyers can select products and add them to their shopping carts.

## 7. Product Details Page

The product details page provides more information about an individual product.

It includes:

- Product name.
- Product description.
- Product price.
- Available stock.
- Vendor or store information.
- Add to Cart option.
- Existing product reviews.
- Review rating and comments.
- Verified Purchase or Unverified Review labels.
- Review submission form.

## 8. Shopping Cart

The shopping cart displays products selected by the buyer.

### Cart Information

- Selected product names.
- Product quantities.
- Individual product prices.
- Subtotals.
- Total purchase amount.
- Remove product option.
- Checkout button.

The system prevents buyers from selecting or purchasing quantities greater than the available stock.

## 9. Checkout Page

The checkout page allows buyers to review and confirm their purchases.

### Checkout Information

- Order summary.
- Selected products.
- Product quantities.
- Individual prices.
- Total purchase amount.
- Confirm Purchase button.

The system checks product availability before processing checkout.

After successful checkout:

- An order is created.
- Product stock is deducted.
- An invoice is generated.
- The invoice is emailed to the buyer.

## 10. Invoice Management

The invoice functionality provides buyers with proof of their purchases.

### Invoice Features

- Invoice number.
- Order information.
- Product details.
- Quantities purchased.
- Product prices.
- Total purchase amount.
- PDF invoice generation.
- Invoice download.
- Invoice delivery by email.

## 11. Reviews Page

The review functionality allows buyers to provide feedback on products.

### Review Features

- Display existing reviews.
- Display review ratings.
- Display review comments.
- Display review dates.
- Allow buyers to submit reviews.
- Identify verified purchases.
- Identify unverified reviews.

A review is marked as verified when the buyer has a completed order containing the reviewed product.

## 12. Password Recovery Page

The password recovery functionality allows users to reset forgotten passwords.

### Password Recovery Features

- Email address field.
- Send password reset link.
- Password reset confirmation page.
- New password field.
- Confirm new password field.
- Password reset success message.

Password reset links expire after two hours.

## 13. Navigation and User Access

The application provides different navigation options according to the user's role.

### Vendors

Vendors can access:

- Home page.
- Vendor dashboard.
- Store management.
- Product management.
- Logout.

### Buyers

Buyers can access:

- Home page.
- Product catalogue.
- Product details.
- Shopping cart.
- Checkout.
- Product reviews.
- Logout.

Buyers cannot access vendor management functionality.

## 14. Design Principles

The application follows these design principles:

- Simple and clear navigation.
- Consistent colours and fonts.
- Clear buttons and labels.
- Easy-to-use forms.
- Responsive layout for different screen sizes, where implemented.
- Helpful error and success messages.
- Consistent page structure.
- Clear feedback after user actions.

## 15. Conclusion

The Jongwa Store interface is designed to make online shopping and vendor management straightforward.

Buyers can browse products, make purchases and submit reviews, while vendors can manage their own stores and products through the vendor dashboard.
